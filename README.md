# Customer-Shopping-Behaviour-Analysis
An interactive Business Analytics Dashboard built using Microsoft Excel, SQL, and Power BI. This project focuses on analyzing customer shopping behavior, tracking key performance indicators (KPIs), and transforming raw data into meaningful business insights through data cleaning, SQL queries, data analysis, and interactive visualizations.
Customer Shopping Behavior Analysis Dashboard
An interactive Business Intelligence project built using Microsoft
Excel, SQL, and Power BI to explore customer shopping behavior and
turn raw data into meaningful business insights.
Project Overview
This project analyzes customer shopping data to understand purchasing
patterns, customer preferences, and business performance. Data was
prepared and analyzed using Excel and SQL, then presented through an
interactive Power BI dashboard.
Tools & Technologies
- Microsoft Excel --- data inspection, cleaning, and preparation
- SQL --- querying, filtering, aggregation, and data analysis
- Microsoft Power BI --- dashboard development, KPI reporting, and
  data visualization
Dashboard KPIs
- Total Customers
- Total Revenue
- Average Purchase Amount
- Average Review Rating
Analysis Areas
- Customer shopping behavior
- Purchase patterns and trends
- Customer demographics
- Product categories
- Revenue and purchasing performance
Project Workflow
1. Inspected and prepared the customer shopping dataset in Excel.
2. Used SQL queries to filter, aggregate, and analyze the data.
3. Connected the prepared data to Power BI.
4. Built an interactive dashboard to present key metrics and insights.
Skills Demonstrated
Excel · SQL · Power BI · Data Cleaning · Data Analysis ·
Data Visualization · Dashboard Development · Business Intelligence
